# Inventario Bodega Mocoa

Canal oficial de descargas. Aquí se publican únicamente APK firmados, comprobantes de integridad, notas de actualización y privacidad.

[Descargar la última versión](https://github.com/ElMachoProgramador/inventario-mocoa-descargas/releases/latest) · [Privacidad](https://elmachoprogramador.github.io/inventario-mocoa-descargas/privacidad.html)

Android solicita confirmar la instalación. Las actualizaciones conservan el paquete y la firma. No desinstales la app para actualizar. No subas inventarios, plantillas, contraseñas ni claves a este repositorio.
